# Modern Minimalist UI Style Guide

## 🎨 Core Color Palette
```css
/* Primary Gradient */
from-[#6566F1] to-[#B977F8]  /* Main accent gradient */
/* Transparency Levels */
{color}/80  /* Solid elements */
{color}/40  /* Containers */
{color}/20  /* Hover effects */
{color}/10  /* Backgrounds */
```

## 💫 Key Design Principles

### 1. Container Structure
```css
/* Base Container */
relative overflow-hidden rounded-2xl
bg-white/40 dark:bg-gray-900/40
backdrop-blur-sm
```

### 2. Interactive Elements
```css
/* Button/Interactive Item */
group relative rounded-full
bg-white/80 dark:bg-gray-800/80
hover:bg-white/90 dark:hover:bg-gray-800/90
transition-all duration-300
```

### 3. Hover Effects
```css
/* Standard Hover Pattern */
transition-transform duration-300 hover:scale-[1.01]
/* Icon Hover */
transition-all duration-300 group-hover:scale-110
```

## 🎯 Common Patterns

### Text Styling
```css
/* Gradient Text */
bg-gradient-to-r from-[#6566F1] to-[#B977F8]
bg-clip-text text-transparent

/* Body Text */
text-gray-700 dark:text-gray-200  /* Primary */
text-gray-600 dark:text-gray-300  /* Secondary */
```

### Component Structure
```css
/* Wrapper */
relative mx-auto max-w-6xl px-4

/* Content Layer */
relative z-10 p-5

/* Background Layer */
absolute inset-0 bg-gradient-to-r 
from-[#6566F1]/15 to-[#B977F8]/15
```

## 🔄 Animation Patterns

### Transitions
```css
/* Standard Transition */
transition-all duration-300 ease-in-out

/* Hover Growth */
hover:scale-[1.01]  /* Subtle */
hover:scale-110    /* Prominent */
```

## 📱 Responsive Patterns
```css
/* Container Queries */
sm:flex-row        /* Layout shifts */
sm:text-left      /* Text alignment */
sm:justify-start  /* Alignment changes */

/* Spacing */
space-y-2 sm:space-y-0  /* Responsive spacing */
gap-2 sm:gap-3         /* Flexible gaps */
```

## 🎆 Visual Effects

### Decorative Elements
```css
/* Bottom Line */
h-0.5 w-32 rounded-full
bg-gradient-to-r from-[#6566F1]/25 to-[#B977F8]/25
group-hover:w-40

/* Glow Effect */
absolute blur-sm
bg-gradient-to-r from-[#6566F1]/20 to-[#B977F8]/20
```

### Interactive States
```css
/* Button States */
disabled:opacity-50
hover:shadow-md
focus:ring-2 focus:ring-[#6566F1]

/* Group Hover */
opacity-0 group-hover:opacity-100
```

## 📐 Layout Guidelines

### Spacing
- Consistent padding: `p-5` for containers
- Gap spacing: `gap-2` to `gap-4`
- Vertical rhythm: `space-y-2` to `space-y-4`

### Width Control
- Container max-width: `max-w-6xl`
- Content padding: `px-4`
- Button padding: `px-3.5 py-1.5`

### Z-Index Layers
```css
z-10  /* Content */
z-20  /* Interactive elements */
z-50  /* Tooltips/Popovers */
```

border-gray-200/50 dark:border-gray-700/50

A comprehensive COD (Cash on Delivery) Calculator for general ecommerce businesses should include the following key features:

1. Core Details:
   - Product Price
   - Order Quantity
   - Delivery Region (Urban, Suburban, Rural)

2. Shipping and Handling Costs:
   - Shipping Fee per Unit
   - Cash Handling Fee (percentage of order value)
   - Insurance Fee (percentage of order value)

3. Risk Factors:
   - Expected Return Rate (percentage of orders)
   - Failed Delivery Rate (percentage of orders)
   - Damaged Goods Rate (percentage of order value)

4. Marketing and Lead Generation:
   - Marketing Cost per Unit
   - Lead Conversion Rate (percentage)
   - Cost per Lead

5. Additional Operational Costs:
   - Packaging Cost per Unit
   - Customer Support Cost per Unit
   - Platform Fees (percentage of order value)

6. Financial Metrics:
   - Gross Revenue
   - Total Costs
   - Net Revenue
   - Profit Margin
   - Break-even Units

7. Detailed Cost Breakdown:
   - Shipping and Handling Costs
   - Risk-related Costs (Returns, Failed Deliveries, Damaged Goods)
   - Marketing and Lead Generation Costs
   - Additional Operational Costs

8. Lead Analysis:
   - Required Leads
   - Total Lead Cost
   - Cost per Conversion

9. Formula Explanations:
   - Clear explanations for how each metric is calculated, including formulas and examples

10. Visualization and Reporting:
    - Interactive charts and graphs to visualize the data (e.g., cost breakdown, profit margins, etc.)
    - Ability to download reports or export the calculator results

This comprehensive COD Calculator should provide ecommerce businesses with a robust tool to analyze their cash on delivery operations, understand the financial implications, identify key cost drivers, and make data-driven decisions to optimize their processes and improve profitability.

The calculator should be designed with a user-friendly interface, allowing seamless input of data and intuitive interpretation of the results. The inclusion of formula explanations and visualization features will further enhance the calculator's usability and make it a valuable resource for ecommerce entrepreneurs and decision-makers.
