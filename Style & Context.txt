performance:

Use React.memo for components that rarely re-render.
Use useMemo for expensive computations or JSX that doesn't change often.
Use useCallback for functions passed to memoized child components.
Lift state only as high as necessary; prefer local state when possible.
Use unique, stable keys for lists to track item changes.
Avoid anonymous functions in render; define them outside or use useCallback.
Use lazy loading for components/routes that aren’t needed immediately.
Implement list virtualization (react-window/react-virtualized) for long lists.
Optimize context with memoization or by splitting contexts.
Use React DevTools Profiler to spot and fix unnecessary re-renders.
